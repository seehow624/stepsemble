# 引用其他 session（AI 交接摘要）

## 已確認範圍

使用者同意：在一個 session 的輸入框中，可以從側欄拖入其他 session。Stepsemble 以獨立、用完即丟的摘要員產生交接摘要，再附進送出的訊息。不寫檔案、不建立分支、不改動來源 session。預設不提供機械目錄；只有摘要員失敗時，才可手動改用精簡版。

## 使用行為

- 從側欄把 session 拖進輸入框，輸入框出現「參考：名稱 · agent」小卡，背景立即開始整理。每則訊息最多參考 3 個 session，可隨時移除。
- 不能拖曳時（鍵盤、手機），用輸入框「＋」選單的「引用 session…」從同一台 Host 的 session 清單搜尋挑選；agent 不收圖片時「＋」直接開清單。
- 小卡依序顯示整理中、完成或失敗。點開可預覽並修改摘要；修改只影響這次送出。
- 送出時，摘要附在使用者文字之後，並標明來源 session 名稱、agent、專案路徑與摘要涵蓋的輪數。摘要尚未完成時，送出等待完成，狀態列可以取消；等待中再按送出不會重複送出，期間切換對話則放棄這次送出。草稿與小卡要等 Host 接受訊息後才清除。
- 同一來源 session 沒有新對話時沿用上次摘要。摘要只存在 Host 記憶體；Host 重啟後重新產生。
- 摘要員未設定、未登入或失敗時，小卡說明原因，並提供重試與「改用精簡版」，不自動切換方式。
- 第一版只支援同一台 Host 的 session。來源可以是任何能讀取歷史的 session；目標是 coding agent 的 session，不含 Hermes。

## 摘要員

- 設定頁讓使用者選擇 agent、模型與思考模式。第一版只開放有原生「不存檔、不用工具」執行方式的 agent：
  - Claude Code：`-p --no-session-persistence`，`--tools` 給空清單，`--model`、`--effort`。
  - Codex：`ephemeral` thread，read-only 沙盒，關閉 shell 工具，指定 model 與 effort。
  - Pi：`--mode rpc --no-session --no-tools --no-extensions --no-mcp --no-skills`，`--model`、`--thinking`。
- 未設定（自動）時，依序選第一個已安裝的 Claude Code、Codex、Pi，以低思考強度與預設模型執行；預覽中顯示實際使用的摘要員。設定中指定的 agent 若未安裝，直接失敗並說明，不改用其他 agent。
- 來源紀錄一律當成資料，不當成指令。摘要員不得執行工具、讀檔或寫檔；結果只回傳文字。

## 內容與大 session

- 由 Stepsemble 既有的原生歷史讀取來源紀錄：使用者訊息與回覆完整保留，工具呼叫只留名稱與主要參數一行，工具輸出與圖片不送出。
- 來源曾經壓縮時，從最近一次原生壓縮摘要開始，只整理之後的對話，並標明摘要涵蓋範圍。
- 依輪數切成每段最多 12 萬字元，以「目前摘要＋下一段」依序更新，小卡顯示進度；固定段長讓上下文較小的摘要員也放得下。預估超過 30 萬 token 時，先請使用者確認。
- 交接摘要固定包含：目標、已完成、重要決定與原因、試過但放棄的做法、尚未完成與注意事項、相關檔案。

## Host 與介面邊界

- 新增 Host 摘要服務：以工作區 entry 解析來源與目標，執行前重新核對身份；同一來源（同一版本與摘要員設定）同時只跑一個摘要工作，全體最多 2 個並行，有界佇列，可取消，Host 關閉時終止子程序。
- 摘要員子程序使用隔離的工作目錄與最小環境，逾時、輸出大小與並行數都有上限；失敗時不重試付費請求，除非使用者按重試。
- 前端新增獨立模組處理拖放、小卡、預覽與送出等待；沿用側欄既有的 `application/x-stepsemble-session` 拖曳資料。
- 11 語系；鍵盤可操作（小卡可聚焦、刪除、開啟預覽）。

## 驗證

- 單元測試：拖放資料驗證、小卡狀態、送出等待與取消、草稿安全、舊回應不影響新視窗、快取與失效、切段與確認門檻、摘要員參數（不存檔、無工具）。
- 協定測試：三種摘要員的精確參數與輸出解析，失敗、逾時、取消與子程序清理。
- 真實 CLI：以隔離 HOME 與本機假模型 API 驗證 Claude Code、Codex、Pi 確實不存檔、無工具。
- 隔離瀏覽器：桌面的拖放、預覽與送出。手機版側欄與對話不會同時顯示，沒有可拖放的目標。
